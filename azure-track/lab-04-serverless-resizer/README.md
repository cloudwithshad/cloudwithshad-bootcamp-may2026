# ⚡ Azure Lab 04: Serverless Image Resizer (Azure Functions + Pillow)

An event-driven serverless pipeline that triggers on photo uploads to Azure Blob Storage and outputs optimized 200px thumbnails in milliseconds.

## 📖 Walkthrough Guide
Open [`index.html`](./index.html) in your browser for the step-by-step guide.

## 📦 Local VS Code Deployment
```bash
pip install -r requirements.txt
# Press F1 -> Azure Functions: Deploy to Function App...
```
