Lightbulb: Core Capstone Concepts for Beginners

1. What is an Azure Functions HTTP API?
Think of a digital front desk concierge. When a user submits feedback on your website, the browser sends an HTTP POST request. The function wakes up, validates the JSON data, orchestrates the AI service, saves the result into the database, and responds with CORS headers in under half a second.

2. What is Real-Time Sentiment Analysis?
Think of an automated emotional pulse detector. Instead of waiting for a human manager to read thousands of customer reviews, Azure AI Language scores each submission across positive, neutral, and negative confidence brackets immediately upon submission.

3. Why Partition Cosmos DB by /sentiment?
Think of pre-sorting documents into three dedicated color-coded file drawers (Green for Positive, Grey for Neutral, Red for Negative). When your executive dashboard queries "How many negative reviews arrived today?", Cosmos DB searches only that exact partition, delivering instant queries at minimal Request Unit (RU) cost.

Moneybag: Capstone Free Tier Safety: Reuse or Enable Free Grant
Azure allows only one Cosmos DB account per subscription to use the Free Tier discount (1000 RU/s + 25 GB free forever). If you created cosmos-doc-analyzer in Lab 7, you can simply create a new database FeedbackDB inside it to stay 100% free. If deploying standalone, remember to select the Apply Free Tier Discount option on the Basics tab.

Phase 5 · HTTP Trigger & VS Code Deployment

Deploy Sentiment API & CORS Configuration

Page 06 · Function API & CORS
💡 Cloud Architect Production Note
To allow your frontend web application to call the serverless API securely, configure CORS (Cross-Origin Resource Sharing) in the portal, then deploy the Python API backend from VS Code with azure-ai-textanalytics and azure-cosmos compiled in requirements.txt.
1
CORS & VS Code Dependencies
1. In Azure Portal, open Function App > API > CORS > enter * under Allowed Origins > click Save.
2. Open your project folder in VS Code.
3. Open requirements.txt and specify the production SDKs:
requirements.txt
azure-functions azure-ai-textanalytics azure-cosmos
4. Press Ctrl + Shift + P → Azure Functions: Deploy to Function App... → Select your Function App → Confirm.
2
Python V2 HTTP API (function_app.py)
Paste the production V2 HTTP trigger and Cosmos DB persistence backend into function_app.py:
function_app.py · Python V2 Model
import json, os, uuid, logging import azure.functions as func from azure.ai.textanalytics import TextAnalyticsClient from azure.core.credentials import AzureKeyCredential from azure.cosmos import CosmosClient app = func.FunctionApp(http_auth_level=func.AuthLevel.ANONYMOUS) @app.function_name(name="submit_feedback") @app.route(route="submit_feedback", methods=["POST"]) def submit_feedback(req: func.HttpRequest) -> func.HttpResponse: try: data = req.get_json() comment = data.get("comment", "") # 1. Analyze sentiment via Azure AI Language (F0 Free Tier) client = TextAnalyticsClient(os.environ["LANGUAGE_ENDPOINT"], AzureKeyCredential(os.environ["LANGUAGE_KEY"])) resp = client.analyze_sentiment([comment])[0] # 2. Persist to Cosmos DB /sentiment partition cosmos = CosmosClient.from_connection_string(os.environ["COSMOS_CONNECTION_STRING"]) container = cosmos.get_database_client("FeedbackDB").get_container_client("Submissions") doc = { "id": str(uuid.uuid4()), "name": data.get("name"), "email": data.get("email"), "comment": comment, "sentiment": resp.sentiment, "scores": { "positive": resp.confidence_scores.positive, "neutral": resp.confidence_scores.neutral, "negative": resp.confidence_scores.negative } } container.create_item(body=doc) return func.HttpResponse( json.dumps({"status": "success", "sentiment": resp.sentiment}), status_code=200, headers={"Content-Type": "application/json"} ) except Exception as e: return func.HttpResponse(f"Error: {str(e)}", status_code=500)
