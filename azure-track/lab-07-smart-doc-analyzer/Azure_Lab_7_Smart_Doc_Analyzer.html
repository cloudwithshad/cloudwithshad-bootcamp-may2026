Lightbulb: Core Cognitive Concepts for Beginners

1. What is Azure AI Document Intelligence?
Think of a high-speed robotic document scanner. It does not just recognize letters; it understands layout, headings, tables, and form fields, turning unsearchable PDFs and images into structured text in seconds.

2. What is Azure AI Language?
Think of a digital comprehension analyst. It reads the extracted text and determines the emotional tone (positive, neutral, or negative) along with key phrases and entities.

3. What is Azure Cosmos DB for NoSQL?
Think of a lightning fast digital filing cabinet. Instead of rigid tables with fixed columns, Cosmos DB stores flexible JSON records that can be indexed and queried with sub-10 millisecond latency worldwide.

Moneybag: Free Tier Protection: F0 Standalone Provisioning Rule
The one-click "Multi-service resource" option in the portal only offers the paid Standard S0 tier. To maintain zero lab cost, provision two separate single-service resources: a standalone Document Intelligence resource (F0 Free) and a standalone Language resource (F0 Free). Additionally, enable the Apply Free Tier Discount on your Cosmos DB account.
Ingestion & AI Processing Tier
Blob Ingestion: Storage container documents receives PDF files.
Document Intelligence: Standalone F0 Free tier (500 pages/mo) running the prebuilt-read OCR model.
Azure AI Language: Standalone F0 Free tier (5,000 text records/mo) analyzing sentiment.
Serverless Orchestration & NoSQL Storage
Orchestration: Azure Function App on Consumption Plan (Python 3.10/3.11).
Database: Azure Cosmos DB for NoSQL (Free Tier enabled).
Database ID: DocAnalyzerDB • Container: AnalysisResults (/document_id).

1
Create Storage & documents Container
1. Sign in to the Azure Portal (portal.azure.com).
2. In top search bar, type Storage accounts and click + Create.
3. Resource group: Click Create new and enter rg-smart-doc-analyzer.
4. Storage account name: Enter unique name (e.g. docanalyzerstore[id]).
5. Region: West US 2 • Redundancy: Standard LRS.

8. Name: documents • Access level: Private > click Create.
2
Create Cosmos DB for NoSQL in Portal
1. In Azure Portal search bar, type Azure Cosmos DB and select it.
2. Click + Create > under Azure Cosmos DB for NoSQL, click Create.
3. Resource Group: rg-smart-doc-analyzer.
4. Account Name: cosmos-doc-analyzer-[id] • Location: West US 2.
5. Capacity mode: Serverless (or Provisioned with Apply Free Tier Discount).
6. Click Review + create > Create (takes ~3 mins).
7. Go to resource > click Data Explorer in the left menu.
8. Click New Container > Database id: Create new DocAnalyzerDB • Container id: AnalysisResults • Partition key: /document_id > click OK.

Phase 5 · VS Code Development & AI Deployment

Orchestrate AI Services & Deploy from VS Code

Page 06 · VS Code AI Workflow
💡 Cloud Architect Production Note
Azure Linux Consumption Function Apps intentionally disable in-portal code editing. Furthermore, external AI SDKs (azure-ai-formrecognizer, azure-ai-textanalytics, azure-cosmos) cannot be compiled inside the browser. We define dependencies in requirements.txt locally in VS Code and deploy with one click using the Azure Functions Extension.
1
VS Code Setup & AI Dependencies
1. Open your project folder in VS Code.
2. Ensure Azure Functions and Python extensions are active.
3. Open requirements.txt and specify the AI and database SDKs:
requirements.txt
azure-functions azure-ai-formrecognizer azure-ai-textanalytics azure-cosmos
4. Press Ctrl + Shift + P (or F1) → Select Azure Functions: Deploy to Function App...
5. Choose your target Function App from the dropdown and confirm deploy.
2
Python V2 Cognitive Pipeline (function_app.py)
Paste the production V2 event-driven AI OCR and sentiment pipeline into function_app.py:
function_app.py · Python V2 Model
import logging, os, uuid import azure.functions as func from azure.ai.formrecognizer import DocumentAnalysisClient from azure.ai.textanalytics import TextAnalyticsClient from azure.core.credentials import AzureKeyCredential from azure.cosmos import CosmosClient app = func.FunctionApp() @app.function_name(name="process_document") @app.blob_trigger( arg_name="myblob", path="documents/{name}", connection="AzureWebJobsStorage" ) def process_document(myblob: func.InputStream): logging.info(f"Analyzing incoming document: {myblob.name} ({myblob.length} bytes)") # 1. Document Intelligence OCR Extraction (F0 Free Tier) doc_client = DocumentAnalysisClient(os.environ["DOC_INTEL_ENDPOINT"], AzureKeyCredential(os.environ["DOC_INTEL_KEY"])) poller = doc_client.begin_analyze_document("prebuilt-read", document=myblob.read()) ocr_result = poller.result() extracted_text = " ".join([line.content for page in ocr_result.pages for line in page.lines]) # 2. Azure AI Language Sentiment Analysis (F0 Free Tier) text_client = TextAnalyticsClient(os.environ["LANGUAGE_ENDPOINT"], AzureKeyCredential(os.environ["LANGUAGE_KEY"])) sentiment_resp = text_client.analyze_sentiment([extracted_text[:5000]])[0] # 3. Store structured JSON analytics into Azure Cosmos DB cosmos_client = CosmosClient.from_connection_string(os.environ["COSMOS_CONNECTION_STRING"]) container = cosmos_client.get_database_client("DocAnalyzerDB").get_container_client("AnalysisResults") record = { "id": str(uuid.uuid4()), "document_id": os.path.basename(myblob.name), "page_count": len(ocr_result.pages), "sentiment": sentiment_resp.sentiment, "positive_score": sentiment_resp.confidence_scores.positive, "extracted_preview": extracted_text[:250] } container.create_item(body=record) logging.info(f"Document analytics successfully persisted to Cosmos DB: {record['id']}")

Teardown & Resource Cleanup via Portal

Page 09 · Resource Teardown
Moneybag: Cost Governance Best Practice
Although Document Intelligence and Language were created on the F0 Free Tier, standard Cosmos DB provisioned throughput (if not serverless) and storage accounts can incur minor ongoing costs. Delete the lab resource group in the Azure Portal after submitting your evidence.
Trash
Portal Deletion Steps
1. In the Azure Portal search bar, type Resource groups and select it.
2. Click on rg-smart-doc-analyzer.
3. Click the Delete resource group button in the top toolbar.
4. Type rg-smart-doc-analyzer in the confirmation field.
5. Click Delete.

Azure will automatically purge the Storage Account, Function App, Cosmos DB account, Document Intelligence, and Language service instances in a single unified operation.
