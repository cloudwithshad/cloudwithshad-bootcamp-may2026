# 🌐 Azure Lab 01: Static Website Hosting on Blob Storage

Build and host a responsive personal developer portfolio globally on Microsoft Azure Blob Storage.

## 📖 Walkthrough Guide
Open [`index.html`](./index.html) (or `Azure_Lab_1_Static_Portfolio.html`) in your browser for the full step-by-step interactive slide deck.

## 🛠️ Architecture
- **Service:** Azure Storage Account (Standard LRS, StorageV2)
- **Container:** `$web` (auto-generated by static website feature)
- **Index Document:** `index.html`
- **Error Document:** `404.html`
